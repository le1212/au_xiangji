# 构图教练 · Composition Coach

一个由视觉大模型驱动的**实时摄影构图教练**网页应用：取景时自动分析画面构图，
在屏幕上画出「目标位置框」引导被拍的人移动，给出大白话动作指令
（"往左挪两步""蹲低一点"），并把每次拍摄会话（诊断过程 + 成片）存档复盘。

## 功能

- **手动构图诊断（默认）**：点「诊断」按钮（或按 D 键）对当前取景帧做一次分析，
  返回构图分 / 问题 / 动作指令 / 主体当前框 / 目标框。每按一次才消耗一次
  token，不自动轮询。
- **识别对象不限人像**：人物、物品、食物、产品、建筑、风光场景都适用，模型会先
  判断主体类型（诊断后显示「主体 · 人物 / 物品 / 场景」标签）再按对应逻辑给建议。
- **视觉动作指引（文字只是辅助）**：
  - 白色框 = 主体当前位置；琥珀色蚂蚁线框 = 目标位置；箭头 = 主体移动方向
  - 构图骨架：穿过目标框中心的对齐辅助线 + 最近三分交点十字锚点 + 建议水平线
  - 左上动作卡：拍摄者动作箭头（左移/右移、蹲低/举高、凑近/后退或变焦、旋转
    校正角度），构图达标后自动消失、四角变绿提示「可以拍了」
- **自动连续模式（可选，默认关）**：设置里勾选后按设定间隔（1~5s）自动诊断，
  费 token，建议只在调试时开。
- **会话存档（全自动持久化）**：一次拍摄 = 一个会话（若干诊断帧 + 成片）。每帧
  诊断即自动写入 IndexedDB，切后台/关闭页面时兜底写盘，重新打开自动恢复上次
  未存档的会话；「存档」按钮将本组标记为完成。支持回看时间线、构图分曲线、
  导出 JSON、删除。
- **快门**：拍下当前画面作为本次成片（快捷键：空格）。
- **前后摄像头切换**，前置时自动处理镜像坐标。

## 运行

需要 Node.js（任意较新版本，无第三方依赖）：

```
node server.js
```

然后打开 **http://localhost:5177**（端口被占用会自动顺延，以命令行输出为准）。

> 相机权限要求安全上下文：`localhost` 可直接使用；用 `file://` 直接双击打开
> HTML 无法调用相机。

### 手机上用（真实使用场景）

手机浏览器访问电脑上的 `http://<局域网IP>:5177` 会因为没有 HTTPS 而拿不到相机权限，
任选其一解决：

1. 用内网穿透工具套一层 HTTPS，例如 `npx localtunnel --port 5177` 或 ngrok；
2. 用自签名证书 + HTTPS 启动任意静态服务器（如 `npx serve --ssl`）。

## 配置模型

首次打开点右上角「设置」：

| 预设 | API 地址 | 视觉模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-v4-flash-vision-exp` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash` |
| 通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-flash` |
| OpenRouter | `https://openrouter.ai/api/v1` | 自行填写 |

- 走 **OpenAI 兼容的 `/chat/completions`** 协议，任何兼容服务商都可以用「自定义」接入。
- API Key 只保存在本机浏览器的 localStorage；画面帧只发给你配置的服务商，
  本应用没有自己的服务器。
- 「测试连接」按钮会先发一条纯文本请求验证 Key 与地址。

## 延迟与 token 成本

- 每次诊断只上传 **640px、JPEG 70%** 的压缩帧；
- prompt 强制模型**只输出一个约 100 token 的 JSON**；
- 单次调用同时完成感知与决策（识别 + 指令 + 目标框坐标），不串联两个模型；
- **默认手动模式**：点一次「诊断」才调用一次（失败自动重试 1 次），token 消耗
  完全可控；自动连续模式默认关闭，仅供调试。

## 已知限制

- **指令的左右语义**：目标框的视觉引导永远和屏幕一致；但前置（自拍）镜像时，
  文字指令里的"左/右"偶尔可能与镜像画面相反，以屏幕上的框和箭头为准。
- **VLM 空间定位精度有限**：目标框是"大致框架"（这正是产品设计），不是像素级精准框。
- **单模型调用**：目前未做"识别模型 + 决策模型"双通道，也暂未做本地人脸检测的
  零延迟叠加层（MVP 后的优化项）。
- iOS Safari 对 getUserMedia 限制较多，若需自动控制相机参数，可能要 Android 原生先行。
- 导出 JSON 在部分 Android WebView 内可能不触发下载（浏览器版正常）。

## 目录结构

```
composition-coach/
├── server.js        # 零依赖静态服务器（localhost:5177）
├── index.html       # 单页应用：取景器 / 档案列表 / 会话详情 / 设置
├── css/style.css    # 暗房光学仪器视觉主题
└── js/
    ├── camera.js    # 取景流、抓帧压缩、前后摄切换
    ├── vlm.js       # 诊断 prompt、OpenAI 兼容调用、JSON 解析归一化
    ├── overlay.js   # canvas 叠加层：三分线/位置框/蚂蚁线目标框/箭头/达标绿框
    ├── store.js     # IndexedDB 会话存档
    └── app.js       # 主控：诊断循环、会话生命周期、视图、设置
```
